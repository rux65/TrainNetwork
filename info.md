train_interface.Train Network 

- This project is aimed at mocking up a network system
- This project looks at creating a simple rail network
- then moving the trains and updating their positions
- the communication between trains is done using kafka 
- the system checks the timetable and moves the trains automatically
- the system keeps track of the train status and updates it accordingly
- system runs in docker 
- trains need to run independent of each other 
- train always maintains a lifesign with system
